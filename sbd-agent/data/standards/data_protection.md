# Data Protection Standard

## ENC-01 Encryption
Encrypt data in transit (TLS 1.2+) and at rest. Prefer platform-managed keys with documented rotation.

## PII-01 Minimization
Collect only personal data required for the business purpose. Define retention and deletion schedules.

## PII-02 Access to regulated data
Restricted and confidential data stores require audited access paths and break-glass procedures.

## CLASS-01 Classification
Every system must declare a data classification (public, internal, confidential, restricted).
Missing classification is a Security-by-Design coverage gap.
