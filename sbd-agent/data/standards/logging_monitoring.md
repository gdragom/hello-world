# Logging and Monitoring Standard

## LOG-01 Security logging
Capture authentication failures, privilege changes, and access to sensitive data. Retain per policy.

## PII-02 Log redaction
Never write raw PII, secrets, or payment data into application logs, traces, or analytics pipelines.

## MON-01 Alerting
Critical security events must page on-call with runbooks. AI agent tool invocations should be audited.
