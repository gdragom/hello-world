# Confirmed Career Target

**Primary path:** AI Engineer / AI Platform Engineer → AI Tech Lead (IC-first).

**Secondary bridge:** AI Security / Agentic Security Lead (keep open for regulated orgs).

## Why this path

Manager experience already signals leadership. Market screens reject shallow agent demos without:

- production MLOps
- evaluation harnesses
- retrieval quality ownership
- cost and reliability SLOs

Build IC credibility with measurable AI systems first, then step into AI Lead with a portfolio that proves you can set standards for others.

## Role targeting order

1. AI Engineer / LLM Application Engineer (Azure-heavy orgs)
2. AI Platform / MLOps Engineer
3. AI Tech Lead / Staff AI Engineer (after 1–2 production stories)
4. AI Security Lead / Agentic Security Architect (parallel bridge)

## Positioning line

> Designed and automated Security-by-Design with a multi-agent LangGraph-style system on Microsoft Foundry patterns, with CI/CD integration, risk scoring, and coverage of security requirements — combining AppSec leadership with agentic AI delivery.

Frame the transition as expanding ownership from assuring systems to building intelligent systems.
