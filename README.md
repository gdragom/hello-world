# hello-world → LEDGER trading journal

This repo hosts **LEDGER**, a Bitget-connected BTC ICT trading journal, plus Cursor MCP config for the official Bitget agent.

```bash
cd journal
cp .env.example .env.local   # BITGET_API_KEY / SECRET_KEY / PASSPHRASE
npm install
npm run dev
```

Bitget MCP (Cursor chat tools): see [`docs/BITGET-MCP.md`](docs/BITGET-MCP.md)  
App details: [`journal/README.md`](journal/README.md)
